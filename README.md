## 下单前必须知道：RackNerd 默认不退款

这是全文最重要的一节。RackNerd 官方条款的原文是：退款按个案（case-by-case）处理，**付款到账后默认不退款**。没有 7 天无理由、没有按比例退还，知识库也明确表示不提供退款保证（money back guarantee）。大量中文测评文章只讲价格不讲这一点，导致不少人买完才发现想退很难。

几个具体规则：

- **账户余额不退**。提前充值的 prepaid credit 只能用于购买服务，不能提现。
- **取消和退款是两件事**。取消只停止续费，不追回已付款项。
- **取消要提前通知**。常规服务（VPS、共享主机等）需在续费日前 5 天通过客户区提交书面取消请求；合同制服务（通常是独服）需 7 天，且可能产生提前终止费。错过了窗口，下一期账单照出，而这笔钱按默认规则是要不回来的。比较稳的做法是设一个续费日前 7 天的日历提醒。
- **数据说没就没**。选择“立即取消”后，系统约 24 小时内终止服务并删除全部数据；欠费的服务多数在到期日后 7 天自动终止，独服更严格，最快 3 天就释放硬件，终止后数据永久清除。取消前务必备份。
- **别直接拒付信用卡**。与滥用相关的 chargeback 会触发 $125–$250 的行政费，账户还可能被暂停。有问题先开工单。
- **逾期有滞纳金**。逾期 3 天后账单可能加收 10% 滞纳金。

退款也不是完全没门：刚开通、还没实际使用就发现服务异常（VPS 起不来、IP 不通）这类情况，礼貌提交 Billing 工单有机会协商；被拒时客服常见的替代方案是转成账户余额、换机房或换更高配置补差价。但这些都是“争取”，不是承诺。

正确的策略是把风险前置：下单前用各机房公开的测试 IP 和测速文件、Looking Glass 自测延迟，确认线路符合预期再付款；不确定的话先月付。
